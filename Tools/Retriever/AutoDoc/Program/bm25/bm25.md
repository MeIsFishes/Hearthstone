# BM25

## 1. 模块说明

BM25 是文档召回和最终计分的唯一核心。模块使用 `jieba.cut_for_search()` 对文档名、完整正文和查询词进行一致分词，再写入 SQLite FTS5 `unicode61` 标题与正文表。

BM25 数据库同时维护 active 文档词项投影和目录级“检索等价词表”。等价词表以“目录 + 单词”为主记录，每个词对外呈现 `equivalent_terms`、`candidate_equivalent_terms`、`non_equivalent_terms` 三张列表，所有词对双向同步。

查询包含原始关键词、已确认等价词和 OOV 临时近邻三条通道；向量相似度只能生成候选或缩放临时近邻，不能直接召回文档或形成文档分数。备选等价词不会自动参加搜索，只会在其所属词出现在命中文档时被抽样交给 Agent 判断。

默认通道权重为原始词 `1.0`、已确认等价词 `0.65`、临时候选 `0.30 × similarity`。每条结果返回匹配词、通道、权重、BM25 分值和最终贡献。

## 2. 对外接口

- `tokenize_for_fts/prepare_fts_text/prepare_match_query`：完成 jieba 分词、FTS 写入文本与 `MATCH` 查询构造。
- `BM25Search.upsert/delete_refs/clear`：在同一事务中维护 FTS 和 `document_terms`。
- `BM25Search.refresh_lexicon/lexicon_terms/known_terms_by_directory`：按 active 引用生成和查询目录词表。
- `BM25Search.recall/score_refs/contains_refs`：召回、重新计分和 generation 完整性校验。
- `BM25Search.add_candidate_pair/accepted_expansions/relation_state`：维护和读取双向三列表词对。
- `BM25Search.review_candidates_for_results`：从命中文档词项的备选列表中限量抽取审核词对。
- `BM25Search.create_review_request/submit_feedback/list_relations/reset_relation`：维护审核、三列表转移和幂等反馈。
- `KeywordSearch.search/search_channels`：执行单通道或多通道 BM25 搜索。
- `RetrieverManager.search/search_detailed/submit_synonym_feedback/list_synonyms/reset_synonym`：应用层入口。

## 3. 调用链路

索引链路：

```text
全文档 chunk
-> jieba 搜索模式分词
-> chunk_title_fts / chunk_body_fts
-> document_terms
-> Catalog 激活 revision
-> refresh_lexicon 只投影 active 引用
-> 词向量近邻批量写入 candidate_equivalent_terms
```

搜索链路：

```text
结构化关键词或兼容 query
-> 原始关键词 exact 通道
-> 已确认关系 accepted 通道
-> OOV 近邻 provisional 通道
-> 各通道分别执行 FTS5 bm25()
-> 按通道权重累加 BM25 contribution
-> final 降序并返回前 k 篇完整文档
-> 从命中文档词项的备选列表抽取 review_requests
```

反馈链路把词对标准化为无方向关系。一次 `equivalent` 会从双方备选列表转入双方等价词列表；前两次 `not_equivalent` 保留在备选列表并累加不同 `search_id`，第三次转入双方非等价词列表；`unsure` 不增加否决数。等价和非等价词对不会被后续索引重新加入备选，只能手动重置。

## 4. 数据来源

- `storage_dir/search/bm25.db`。
- `chunk_title_fts`、`chunk_body_fts`：标题与完整正文的 FTS5 索引。
- `document_terms`、`lexicon_terms`：文档词频和 active 目录词表。
- `equivalence_terms`：以目录和单词为主键的等价词表主记录。
- `equivalence_entries`：双向的 equivalent、candidate、non_equivalent 列表条目、相似度和否决计数。
- `synonym_relations`：旧版词对状态，仅用于一次性迁移。
- `synonym_review_requests`、`synonym_feedback_events`：带 search ID 的审核与幂等事件。
- 临时表 `allowed_chunks`：将召回限制在 Catalog active 引用内。
- `BM25Config` 与 `SearchConfig`：分词版本、候选数量、通道权重、OOV 阈值、冷却和否决次数。

## 5. 与其他模块的依赖

- 依赖 `jieba-py` 和 Python SQLite FTS5。
- 依赖文档数据库提供 active 引用和完整正文。
- 接收向量数据库在索引后生成的词表近邻，以及 OOV 查询产生的临时近邻；最终文档得分始终是 BM25。
- HTTP、CLI 和 MCP 通过 Manager 调用本模块。
