# 加载界面美术模块文档

## 1. 模块范围

本模块覆盖 Stage 加载期间全屏显示的单张静态背景图，以及该图片在 Loading View 中的视觉使用范围。运行资产位于 `Assets/Resources/Art/Loading/UI/`，对应页面为 `Assets/Resources/Ui/LoadingView.prefab`。

## 2. 模块风格

加载画面沿用项目的木质、暖金金属、深蓝漆面和蓝宝石魔法视觉语言，并使用比战斗与备战页面更低的环境亮度。画面从略高机位俯视雕花胡桃木卡桌，六张蓝金卡背围绕中央发光水晶构成放射式中心构图；边缘以酒馆器物和深色暗角收束，重要主体集中在中央约 `70%` 安全区。

画面为完整横向环境插画，不承载文字、标题、品牌标志、进度条、百分比、旋转图标或水印。暖橙烛光只负责环境层次，蓝色水晶与卡背宝石形成最高亮度和冷暖对比。
