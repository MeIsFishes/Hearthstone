# UI 按钮与备战区拖放音效任务报告

## 任务结果

任务已完成。所有通过 BbxCommon `UiViewBase` 创建的 UI 页面与条目，会在 View 首次初始化时为直属 `Button` 统一注册 `click_001` 点击音，音量为 `0.7`。备战页卡牌成功放入或移动到出战槽时播放一次 `drop_001`，音量为 `0.78`；取消拖放、无效目标和放回原槽不会播放落位音。

## 实现与框架边界

- `Assets/Scripts/BbxCommon/Ui/Mvc/UiViewBase.cs`：在既有 UI 生命周期内一次性扫描当前 View 直属按钮；扫描包含 inactive 子层，使用最近父 View 过滤嵌套页面，并用实例标记避免池化重开重复注册。
- `Assets/Scripts/Hearthstone/Ui/Controller/PreparationController.cs`：复用 `RunCardRules.TryPlaceCard()` 的成功返回值作为唯一落位音触发条件。
- 两类声音均通过公开 `AudioApi.Play()` 播放，并由既有 `ResourceApi` / `AudioManager` 加载和池化；没有新增全局输入监听、音频管理器、手写资源路径加载或 Prefab 旁路。
- 框架改动为局部、向后兼容的小改动，不改变公开 API、核心生命周期、数据格式或导出资产。
- 复用的 `click_001.ogg` 与 `drop_001.ogg` 在 `Assets/Resources/` 中各只有一份，资源 key 无歧义。
