# 备战发牌逻辑修改报告

## 任务结果

已完成。正常游戏流程的首次备战奖励和后续每轮备战奖励均改为：从编号 `1~98` 的普通卡中排除当前不可用编号后，无放回随机生成 5 张编号互异的卡。后续轮次排除 Run state 当前已持有卡；首轮额外排除开局自动加入阵容的 `{4,1,40}`。抽中卡牌的永久攻击力和最大生命值按其 `BattleCardTypeCsvData` 范围随机生成。
