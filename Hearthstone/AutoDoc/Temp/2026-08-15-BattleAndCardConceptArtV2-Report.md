## 最终提示词摘要

### 俯视 UI 战斗场景第二版

- 输入图片：`battle-scene-concept.png`，角色为编辑目标。
- 编辑要求：改为接近 90 度正俯视、UI 主导的 16:9 战斗概念稿；上下两排各三卡，中央留出战斗反馈区域；浅暖色底板、简化边框、均匀照明和克制的魔法攻击线。
- 保持项：敌方红框哥布林战士、弓手、投弹手；我方蓝框抽象卡面；三对三和正向卡牌。
- 禁用项：酒馆空间透视、桶、酒杯、烛台等繁杂道具；文字、数字、伪文字、商标、品牌标识、水印与商业 UI 直接模仿。

### 明亮奇幻五怪物卡面第二版

- 输入图片：`monster-card-fronts-concept.png`，角色为编辑目标。
- 编辑要求：五张卡保持原顺序，角色缩小到主视觉约 `60%–67%`，露出约三分之一环境；采用天空、树林、遗迹、魔法雾和发光粒子；提高亮度与色彩，改为干净数字绘画和轻量笔触。
- 保持项：哥布林战士、弓手、投弹手、野猪、单头食人魔；统一红金框、空说明区、左绿生命角标、右橙攻击角标。
- 禁用项：近距离大头像、主体超过主视觉三分之二、厚重油画堆叠、暗黑写实、文字、数字、伪文字、商标、品牌标识、水印与商业卡框直接模仿。

生成方式：内置 `image_gen`，使用本地图片编辑模式；未使用 CLI 或 API fallback。
