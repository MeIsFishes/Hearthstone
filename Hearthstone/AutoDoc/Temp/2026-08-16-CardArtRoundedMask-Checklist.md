# 卡面圆角遮罩生成检查清单

- [ ] 确认用户目标：结合当前卡牌外形轮廓，将卡面显示区域由方角改为圆角；本次先生成透明遮罩层预览，不改变卡框。
- [ ] 检查工作区现状与相关卡牌资源，识别卡牌外轮廓、卡框、卡面图及现有遮罩/材质/UI 实现，避免误改无关文件。
- [ ] 使用 imagegen 内置模式生成项目用透明位图遮罩；以本地卡牌图像作为参考，保持轮廓匹配、边缘干净、无文字、无水印、无额外装饰。
- [ ] 将最终遮罩保存到项目 `Assets/` 范围内，采用不覆盖既有资产的独立文件名，并且不创建、编辑或删除任何 `.meta` 文件。
- [ ] 视觉与文件验证：检查透明通道、圆角轮廓、尺寸/宽高比、边缘质量，以及作为卡面遮罩时是否不会覆盖卡框。
- [ ] 框架边界审计：确认本次资产流程未绕过项目已有资源/UI/材质框架或导出流程；若只生成未接线预览，明确记录其尚未被运行时引用。
- [ ] 代码复用审计：若未涉及代码则标记不适用；若涉及代码，检查新增函数和字段是否具有复用价值并删除一次性抽象。
- [ ] 玩家视角设计文档：完整读取设计文档格式 skill，核对实际玩家可见现状变化、相关现有文档与是否需要同步。
- [ ] 美术文档：完整读取美术文档 skill，核对遮罩资产的实际落地、相关现有文档与是否需要同步。
- [ ] 程序文档：完整读取程序文档格式 skill，核对运行时实现是否变化、相关现有文档与是否需要同步。
- [ ] 结束审计：逐项记录通过/未通过/不适用及证据，修正可修正缺口。
- [ ] 只运行一次 `AutoDoc/CleanupTempDocs.bat`，记录退出结果；随后创建同任务名 `*-Report.md`。
