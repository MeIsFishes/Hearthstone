# 战斗与备战羊皮纸做旧纹理报告

## 结果

战斗棋盘与备战上区现在共用同一张透明羊皮纸做旧 Sprite：`Assets/Resources/Art/Preparation/UI/ParchmentAgingOverlay.png`。做旧层只包含零星淡褐斑点、柔和水渍边与少量短划痕；备战以 `18%` 整体 Alpha、战斗以 `14%` 整体 Alpha 叠加，原有整页背景、木框和金边均保持不变。

## 资源关系

原实现中的 `PreparationPageBackground.png` 与 `BattleBoardBackground.png` 不是同一资源：前者同时包含备战上方羊皮纸和下方蓝色卡池结构，后者包含完整战斗棋盘框体，无法在不破坏布局的情况下互换。本次将可共享的“羊皮纸表面做旧”拆成独立透明层，使两个界面实际引用同一个 Sprite 与 GUID，同时保留各自结构背景。

## 实施内容

- 新增 `ParchmentAgingOverlay.png`，尺寸 `1672 × 941`，真实透明背景。
- Unity 导入设置：Single Sprite、Alpha Is Transparency、关闭 Mipmap、Bilinear、CompressedHQ、最大尺寸 2048。
- `PreparationViewUiBuilder` 在背景之后创建 `1700 × 380 @ (0, -270)` 的静态做旧层，Alpha 为 `0.18`，不接收射线，并通过 `Build()` 重建 `PreparationView.prefab`。
- `BattleView.prefab` 通过 Unity `PrefabUtility` 添加静态做旧层，锚点范围 `(0.055, 0.07)` 至 `(0.945, 0.93)`，Alpha 为 `0.14`，不接收射线。
- 两个做旧层均为根节点第 2 个子级，位于背景之后、内容之前。
- 新增 EditMode 测试，验证两处引用同一 Sprite、Alpha、射线开关与 Rect 参数。

## imagegen 使用记录

- 模式：内置 imagegen。
- 用例：`background-extraction` / 透明 Unity UI overlay Sprite。
- 第一版输出因棋盘格被烘入 RGB 而淘汰，没有写入项目。
- 最终修正提示词：`remove the entire visible gray-and-white checkerboard and every white/background pixel ... converting all background pixels to true alpha 0; preserve only the existing faint warm-brown foxing speckles, water-stain edges, and short crease/scuff marks`，并约束无底色、无边框、无文字、无水印、无新痕迹。
- 最终 Alpha 采样：最小值 `0`、最大值 `224`、无 `255` 全不透明采样点；界面整体 Alpha 会进一步衰减。
