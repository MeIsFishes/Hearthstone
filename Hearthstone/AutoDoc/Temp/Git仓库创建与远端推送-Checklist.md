- [ ] 检查待提交范围和忽略规则，排除 Unity 生成目录、凭据、密钥及明显不应入库的大型临时文件。
- [ ] 在目标目录初始化或复用 Git 仓库，并保留用户现有文件与修改。
- [ ] 配置可用远端；在远端信息缺失时明确记录阻塞，不猜测仓库地址或擅自创建外部仓库。

- [ ] 框架边界审计：本任务仅处理版本控制元数据，不绕过 Unity 项目框架、资产流程或编辑器配置源。
- [ ] 玩家视角设计文档：核对本次版本控制操作是否改变玩家可见设计；预计不适用，结束时以实际改动复核。
- [ ] 美术文档：核对本次版本控制操作是否改变美术资产规范或内容；预计不适用，结束时以实际改动复核。
- [ ] 程序文档：核对本次版本控制操作是否改变程序功能或架构；预计不适用，结束时以实际改动复核。
- [ ] 检查无关文件是否被误改，并记录验证证据。
- [ ] 结束前逐项审计，运行一次 `AutoDoc/CleanupTempDocs.bat`，随后创建对应报告。
