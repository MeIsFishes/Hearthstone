# 备战阶段页面等宽卡位原型 V4

> V4 使用确定性 SVG 栅格绘制，不再依赖生成式图像估算卡位尺寸。本稿只用于确认布局，不代表功能已经实现。

## 1. 确定布局

1. 页面上方固定展示 3 个战斗槽位。
2. 页面下方为可纵向滑动的 `1~98` 编号卡池。
3. 卡池每排 7 张完整竖向卡面，首屏显示 `01~14` 两排。
4. 每个卡池卡位固定为 `160×240`，严格保持 `2:3` 比例。
5. 七列起始 X 坐标为 `100`，列步进为 `190`，因此相邻卡位固定间距为 `30`。
6. 两排 Y 坐标分别为 `410` 和 `665`，卡位固定行距为 `15`。
7. 已拥有卡与未拥有空槽复用相同的外框尺寸，只改变卡槽内部内容。

![备战阶段页面等宽七列原型](preparation-stage-ui-prototype-v4.png)

## 2. 精确几何参数

| 参数 | 数值 |
| --- | --- |
| 画布 | `1672×941` |
| 卡位尺寸 | `160×240` |
| 列数 | `7` |
| 首屏行数 | `2` |
| 列坐标 | `100, 290, 480, 670, 860, 1050, 1240` |
| 行坐标 | `410, 665` |
| 横向间距 | `30` |
| 纵向间距 | `15` |
| 已拥有示例 | `01, 04, 07, 12` |
| 空槽示例 | 其余编号，外框尺寸不变 |

## 3. 版本结论

V1～V3 是生成式视觉草图，只保留作方向对照，不能作为尺寸基准。V4 的 14 个卡位由数值坐标和统一组件尺寸生成，是后续 UI 实现的当前布局基准。实际实现时应使用统一卡槽 Prefab 和固定尺寸的 Grid Layout，而不是分别缩放卡牌与空槽。

## 4. 原型边界

本稿不定义卡牌选择、拖放、重复卡处理、出售、刷新、锁定、费用、升级或进入下一轮的规则，也不修改 Unity、代码、配置或正式美术资源。
