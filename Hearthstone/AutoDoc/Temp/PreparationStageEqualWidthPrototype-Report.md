## 执行偏差

V1～V3 使用生成式图像，无法保证像素级重复组件尺寸，因此不再作为布局实施基准。V4 改为 SVG 矢量原型，并通过固定数值导出 PNG。

## 未解决风险

当前仍是布局原型。实际 Unity UI 实现时必须通过统一卡槽 Prefab、固定尺寸约束和 Grid Layout 参数复现这些数值；卡牌选择、拖放、重复卡处理和进入下一轮规则仍未定义。
