# 存档系统设计文档

## 1. 存档方式

当前保存一份卡牌图鉴解锁记录，以及各项新手引导是否已经触发的本机记录；不提供多个档位或手动选择存档。两类记录都与单局状态分离。

## 2. 自动存档

玩家在备战阶段首次抽到可收藏卡、成功融合出可收藏卡，或系统首次发现当前局已经持有但尚未登记的卡时自动保存图鉴。首次成功打开备战新手引导时，系统自动登记该引导已经触发。

## 3. 存档内容

图鉴文件保存格式版本和所有已经解锁的可收藏卡牌编号；本机偏好记录另行保存备战新手引导的触发标记。四卡融合结果、99 号卡池分隔位、卡牌副本数、随机攻血、编队和当前战斗进度均不保存到图鉴文件或引导标记。

## 4. 其他

主菜单右上角的红色“清除数据”调试按钮会删除图鉴存档并清除新手引导触发标记；之后再次进入备战时会重新显示引导。图鉴读取不到或内容损坏时，系统忽略无效内容并以空收藏继续运行。
