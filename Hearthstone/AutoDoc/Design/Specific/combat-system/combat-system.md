# 战斗系统设计文档

## 1. 战斗模式

当前战斗采用自动交替行动模式。玩家与敌方各有三张战斗卡牌，战斗开始后不需要玩家手动选择攻击者或目标。

双方以固定时间间隔轮流行动。我方先行动；同一方存活卡牌按照从左到右的顺序依次成为攻击者，死亡卡牌会被跳过。攻击目标从对方存活卡牌中随机选择。

## 2. 单场战斗流程

进入主场景后直接建立一场战斗并创建双方各三张卡牌。当前固定阵容为：

- 我方：哥布林战士、野猪、食人魔。
- 敌方：哥布林弓手、哥布林投弹手、哥布林战士。

每张卡牌拥有 `1~98` 范围内的唯一编号，编号显示在卡面左上角的灰色六边形底框中。编号与怪物种类、原画的对应关系固定保存在本地配置内；五种怪物分别占有 `19~20` 个编号。食人魔编号从 `35~98` 的候选范围随机抽取，因此整体偏大但不独占最大号段。

每张卡牌使用编号对应的怪物名称和原画。首次玩家阵容的攻击力与最大生命值从怪物种类范围内生成一次并持久保存，之后玩家战斗直接使用备战阵容的永久数值；敌方仍在每场战斗进入时从种类范围内随机生成。当前五种怪物都会在初始双方阵容中出现。

战斗持续到一方全部卡牌死亡：

- 敌方全部死亡时显示“胜利”。
- 我方全部死亡时显示“失败”。
- 战斗未结束时，界面中央仅显示“战斗进行中”，不额外显示“我方”或“敌方”阵营文字标记。

结果首次确定后，游戏自动进入备战卡池界面。

## 3. 回合结算流程

1. 等待当前行动间隔结束。
2. 检查双方是否仍有存活卡牌。
3. 从当前行动方上次的位置继续向右寻找下一张存活卡牌。
4. 从对方所有存活卡牌中随机选择目标。
5. 标记本次攻击者与目标，攻击者向敌方方向前拱后退回；目标卡面同时播放由攻击者种类决定的帧动画与延迟音效。
6. 到达该种类配置的受击延迟时，目标闪红一次，并结算主目标、反击及相邻溅射伤害。
7. 位移、帧动画和受击反馈全部结束后更新死亡状态并再次检查胜负。
8. 若战斗继续，切换到另一方并重新等待行动间隔；动画尚未结束时不会开始下一单位行动。

## 4. 伤害结算流程

攻击者与目标在配置的受击时点同时对彼此造成等于自身攻击力的伤害。受击者卡面在同一时点闪红，生命数字立即响应；死亡状态与胜负在本次攻击动画完整结束后提交。结算后的生命值不会低于零，也不会高于最大生命值；生命值降为零时卡牌进入死亡状态。

当前战斗没有治疗、护盾、减伤、暴击或伤害类型差异。

## 5. 单位系统

当前战斗单位只有战斗卡牌。双方各固定三个槽位，卡牌死亡后保留原槽位但不再参与后续行动或目标选择。离开战斗阶段时，双方本场 Entity 与战斗状态一起清理；玩家持有卡、永久攻血和三槽阵容保留在整局状态中。

卡牌的画面实例由界面条目统一创建和回收，不作为场景中的独立战斗物体。

## 6. 单位属性

当前卡牌具有以下主要属性：

- 攻击力：决定该卡牌每次同时伤害结算时对目标造成的伤害。
- 最大生命值：决定卡牌进入战斗时的生命上限。
- 当前生命值：受到伤害后实时变化；降为零时卡牌死亡。
- 入场基准：卡牌实际进入本场战斗时的攻击力和当前生命值分别作为本场固定比较基准，后续数值变化不会移动该基准。
- 阵营：区分我方与敌方，并决定行动方向和目标关系，不再决定卡面边框颜色。
- 等阶：卡牌进入本次游戏后携带铜、银、金或传奇等阶。基础卡为铜阶，2 张、3 张、4 张素材融合出的结果依次为银阶、金阶、传奇阶；等阶决定卡面边框颜色。

| 怪物 | 攻击力范围 | 最大生命值范围 |
| --- | ---: | ---: |
| 哥布林战士 | 2~4 | 5~7 |
| 哥布林弓手 | 3~5 | 3~5 |
| 哥布林投弹手 | 4~6 | 2~4 |
| 野猪 | 3~5 | 4~6 |
| 食人魔 | 5~7 | 6~8 |

所有范围均为包含最小值与最大值的整数范围。食人魔攻血区间中值约为其他四种怪物平均区间中值的 `1.5` 倍。

## 7. 主要的本地配置

战斗卡牌使用两张 CSV 配置：怪物种类表保存显示名称、默认等阶、生命与攻击范围，以及攻击帧动画资源键、攻击音效资源键、音效延迟和受击延迟；编号表保存 `1~213` 的内部唯一编号、种类关联、原画和融合公式。`99` 是不可参战的封印分隔位；`100~148` 是 15 种双卡与 34 种三卡结果，`149~213` 是 65 种四卡传奇结果。融合种类的攻击、生命和初始词条配置留空，战斗实际使用备战融合时由全部素材相加、合并得到的永久实例属性；其攻击表现配置按公式中的基础怪物特征复用现有五种反馈。

## 8. 其他

战斗界面使用木质外框、金色嵌边和浅暖色羊皮纸战场底板，上下各保留三个对称卡位，中央留出战斗状态与结果反馈区域。羊皮纸表面偶尔出现轻微淡斑、水渍边或短划痕，与备战上区保持一致的做旧质感；痕迹不会形成高对比污渍或遮挡战斗信息。界面不显示“我方”“敌方”侧别标题，也不显示额外页头标题。

战斗卡牌为 `250 × 360` 的竖向长方形。怪物原画使用占卡面约 `82.5%` 高度的视窗展示，并统一铺成略宽于标准 `2:3` 的主体构图；立绘左右各保留约 `20 px` 边距，减少无效空隙。下部使用放大后的深色说明区显示怪物名称与后续说明内容。说明底板带有低透明度的浅金色稀疏菱形、圆点和波纹装饰，两侧分布并避开中央主要文字区域。

敌我双方共用同一张轻薄中性边框，并按卡牌等阶着色：铜阶为铜棕、银阶为冷银、金阶为暖金、传奇阶为明亮紫罗兰；敌我阵营不再改变框色，双方卡牌均保持正向。窄框完整包围怪物立绘和下侧说明栏，底部两侧属性徽章仍会自然露出框外；所有怪物原画统一使用相同的稍宽构图，避免因资源导入比例不同而出现横向压窄。左上角以深灰金属六边形底框显示卡牌编号，左下角以绿色血滴徽章显示生命值，右下角以无剑红金外框显示攻击力。攻击与生命数字分别和各自的入场基准比较：降低时显示红色，提高时显示蓝色，相等时保持白色；两项独立判断，深色描边始终保留。备战卡池、出战槽和融合槽没有本场战斗基准，因此保持白色数字。基础边框、攻击者高亮框和目标高亮框都位于生命、攻击与编号标志下方；攻击者与目标状态继续使用独立状态色，不会覆盖基础等阶含义或切换成粗边框。阵亡状态使用独立遮罩反馈。界面中文使用支持简体中文字符的字体显示。

攻击时，发起方沿双方相对方向短促前拱并平滑退回原位；目标卡面播放八帧透明特效并在受击点闪红。哥布林战士使用剑痕，哥布林弓手使用从斜上方射入的箭矢，哥布林投弹手使用小型爆炸，野猪使用小型击打，食人魔使用大型击打。五种反馈分别使用现有音效库中的刀刃、木质箭矢、爆炸及轻重拳击音效。
