# 战斗系统设计文档

## 1. 战斗模式

当前战斗采用自动交替行动模式。玩家与敌方各有三张战斗卡牌，战斗开始后不需要玩家手动选择攻击者或目标。

双方以固定时间间隔轮流行动。我方先行动；同一方存活卡牌按照从左到右的顺序依次成为攻击者，死亡卡牌会被跳过。攻击目标从对方存活卡牌中随机选择。

## 2. 单场战斗流程

进入主场景后直接建立一场战斗并创建双方各三张卡牌。当前固定阵容为：

- 我方：哥布林战士、野猪、食人魔。
- 敌方：哥布林弓手、哥布林投弹手、哥布林战士。

每张卡牌拥有 `1~98` 范围内的唯一编号，编号显示在卡面左上角的灰色六边形底框中。编号与怪物种类、原画的对应关系固定保存在本地配置内；五种怪物分别占有 `19~20` 个编号。食人魔编号从 `35~98` 的候选范围随机抽取，因此整体偏大但不独占最大号段。

每张卡牌使用编号对应的怪物名称和原画。攻击力与最大生命值在进入战斗时，从该怪物种类的整数范围内随机生成；当前五种怪物都会在初始阵容中出现。

战斗持续到一方全部卡牌死亡：

- 敌方全部死亡时显示“胜利”。
- 我方全部死亡时显示“失败”。
- 战斗未结束时，界面中央仅显示“战斗进行中”，不额外显示“我方”或“敌方”阵营文字标记。

## 3. 回合结算流程

1. 等待当前行动间隔结束。
2. 检查双方是否仍有存活卡牌。
3. 从当前行动方上次的位置继续向右寻找下一张存活卡牌。
4. 从对方所有存活卡牌中随机选择目标。
5. 标记本次攻击者与目标，并同时结算双方受到的伤害。
6. 更新死亡状态并再次检查胜负。
7. 若战斗继续，切换到另一方行动。

## 4. 伤害结算流程

攻击者与目标同时对彼此造成等于自身攻击力的伤害。结算后的生命值不会低于零，也不会高于最大生命值；生命值降为零时卡牌进入死亡状态。

当前战斗没有治疗、护盾、减伤、暴击或伤害类型差异。

## 5. 单位系统

当前战斗单位只有战斗卡牌。双方各固定三个槽位，卡牌死亡后保留原槽位但不再参与后续行动或目标选择。离开战斗阶段时，双方卡牌与本场战斗状态一起清理。

卡牌的画面实例由界面条目统一创建和回收，不作为场景中的独立战斗物体。

## 6. 单位属性

当前卡牌具有以下主要属性：

- 攻击力：决定该卡牌每次同时伤害结算时对目标造成的伤害。
- 最大生命值：决定卡牌进入战斗时的生命上限。
- 当前生命值：受到伤害后实时变化；降为零时卡牌死亡。
- 阵营：区分我方与敌方，并决定卡面使用蓝金或红金边框。

| 怪物 | 攻击力范围 | 最大生命值范围 |
| --- | ---: | ---: |
| 哥布林战士 | 2~4 | 5~7 |
| 哥布林弓手 | 3~5 | 3~5 |
| 哥布林投弹手 | 4~6 | 2~4 |
| 野猪 | 3~5 | 4~6 |
| 食人魔 | 5~7 | 6~8 |

所有范围均为包含最小值与最大值的整数范围。食人魔攻血区间中值约为其他四种怪物平均区间中值的 `1.5` 倍。

## 7. 主要的本地配置

战斗卡牌使用两张 CSV 配置：怪物种类表保存五种怪物的显示名称、生命整数范围和攻击整数范围；编号表保存 `1~98` 的连续唯一编号，以及每个编号对应的怪物种类和原画。当前五种怪物均有独立原画。

## 8. 其他

战斗界面使用木质外框、金色嵌边和浅暖色羊皮纸战场底板，上下各保留三个对称卡位，中央留出战斗状态与结果反馈区域。界面不显示“我方”“敌方”侧别标题，也不显示额外页头标题。

战斗卡牌为 `250 × 360` 的竖向长方形。怪物原画使用占卡面约 `82.5%` 高度的视窗展示，继续保持以原画为主体的卡面比例；下部使用放大后的深色说明区显示怪物名称与后续说明内容。

敌方卡牌使用轻薄红金奇幻边框，我方卡牌使用同造型轻薄蓝金边框；双方卡牌均保持正向。左上角以深灰金属六边形底框显示卡牌编号，左下角以红色剑形徽章显示攻击力，右下角以绿色血滴徽章显示生命值。攻击者与目标状态沿用当前阵营的同尺寸窄边轮廓进行高亮，不会在行动过程中切换成粗边框；阵亡状态使用独立遮罩反馈。界面中文使用支持简体中文字符的字体显示。
