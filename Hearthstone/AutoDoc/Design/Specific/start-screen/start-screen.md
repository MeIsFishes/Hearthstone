# 开始界面设计文档

## 1. 开始游戏的过程

游戏启动并完成初始资源加载后，先进入《99升变》主菜单，不会自动创建新一局或直接进入备战。主菜单当前为静态界面，没有开场动画。

主菜单以一张铺满横屏的做旧羊皮纸为背景，左右边缘分别是相向的哥布林战士与弓手壁画。壁画使用褪色、低对比的中世纪板绘质感，中央空白区域用于显示深棕金边的“99升变”标题和开始按钮。

## 2. 主界面按钮

当前主菜单只有“开始游戏”按钮。按钮具有默认、鼠标经过、按下和不可用视觉反馈；首次点击后会立即禁用，避免重复开始。

## 3. 如何开始游戏

玩家点击“开始游戏”后不需要再做额外选择。游戏建立一个新的本局状态，按第 1 轮配置随机摸牌并进入备战界面；主菜单在阶段切换时卸载。
