# 开始界面设计文档

## 1. 开始游戏的过程

游戏启动并完成初始资源加载后，先进入《99升变》主菜单，不会自动创建新一局或直接进入备战。主菜单当前为静态界面，没有开场动画。

进入主菜单后会循环播放大厅背景音乐。开始新一局进入备战时沿用同一首音乐，不会因大厅与备战页面切换而从头重播。

主菜单以一张铺满横屏、中央留白的做旧羊皮纸为背景。左侧剑盾哥布林和右侧弓箭哥布林不再与背景合成，而是作为独立的深棕剪影立于两侧并朝向中央；人物以清晰外轮廓和少量内在线条表现装备与肢体。界面显示后，两名哥布林以约每帧 `0.3` 秒的极慢速度连续播放 12 帧轻微呼吸与重心摆动：从第 0 帧正向播放至第 11 帧后立即倒序返回，第 0 帧后又立即进入下一轮正向播放，端点不额外停顿。逐帧切换时两名角色的脚底与站立中心保持稳定，不会因图集裁切位置变化而上下或左右跳动。进入图鉴等隐藏主菜单的状态时动画停止，返回主菜单后从起始姿势重新开始。中央上方显示由旧黄铜、烟褐和暗木色构成的低饱和“99升变”绘制标题。

## 2. 主界面按钮

当前主菜单中央从上到下排列“开始游戏”“图鉴”和“退出游戏”三个按钮；三者使用相同字号并作为一个紧凑的纵向按钮组排列在标题正下方。三个按钮常态只显示深棕文字，没有边框或常驻底板；鼠标经过与按下时，文字后方出现半透明的浸湿羊皮纸痕迹，其中前两个按钮为低饱和灰褐色，“退出游戏”为红色。“图鉴”打开局外卡牌收藏页，返回后仍停留在主菜单。“开始游戏”首次点击后会立即禁用，避免重复开始；“退出游戏”关闭当前游戏程序。

主菜单中的每次有效按钮点击都会播放统一的短促点击声；已经禁用的按钮不会响应点击，也不会播放该反馈。

右上角另有红色“清除数据”临时调试入口。点击后清除图鉴解锁记录和新手引导触发记录，不影响局内卡组或其他状态；之后再次进入备战会重新显示新手引导。

主菜单羊皮纸右下角带有向内上翻的卷边；左下角以黑色小字显示当前游戏版本，避开卷边区域。当前版本为 `v0.1.0`。

## 3. 如何开始游戏

玩家点击“开始游戏”后不需要再做额外选择。游戏建立一个新的本局状态，按第 1 轮配置随机摸牌并进入备战界面；主菜单在阶段切换时卸载。
