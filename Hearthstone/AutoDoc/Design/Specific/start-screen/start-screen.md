# 开始界面设计文档

## 1. 开始游戏的过程

游戏启动并完成初始资源加载后，先进入《99升变》主菜单，不会自动创建新一局或直接进入备战。主菜单当前为静态界面，没有开场动画。

进入主菜单后会循环播放大厅背景音乐。开始新一局进入备战时沿用同一首音乐，不会因大厅与备战页面切换而从头重播。

主菜单以一张铺满横屏的做旧羊皮纸为背景，左右边缘分别是相向的哥布林战士与弓手壁画。壁画使用褪色、低对比的中世纪板绘质感，中央上方显示由旧黄铜、烟褐和暗木色构成的低饱和“99升变”绘制标题；标题位置相对先前文字标题上移，为中央操作区留出更安静的留白。

## 2. 主界面按钮

当前主菜单中央有“开始游戏”和“图鉴”两个按钮。两者常态只显示深棕文字，没有边框或常驻底板；鼠标经过与按下时，文字后方出现低饱和灰褐色、半透明的浸湿羊皮纸痕迹。“图鉴”打开局外卡牌收藏页，返回后仍停留在主菜单。“开始游戏”首次点击后会立即禁用，避免重复开始。

主菜单中的每次有效按钮点击都会播放统一的短促点击声；已经禁用的按钮不会响应点击，也不会播放该反馈。

右上角另有红色“清除数据”临时调试入口。点击后只清除图鉴解锁记录，不影响局内卡组或其他状态。

主菜单右下角以黑色小字显示当前游戏版本；当前版本为 `v0.1.0`。

## 3. 如何开始游戏

玩家点击“开始游戏”后不需要再做额外选择。游戏建立一个新的本局状态，按第 1 轮配置随机摸牌并进入备战界面；主菜单在阶段切换时卸载。
