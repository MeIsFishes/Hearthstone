# 战斗系统设计文档格式

如果游戏有战斗环节，则应当写一篇战斗系统文档。

只在当前任务上下文涉及战斗环节时检查或编写。

文档 `.md` 文件名和文件夹路径必须使用英文。

路径限定：战斗系统设计文档是特殊设计文档，统一放在 `AutoDoc/Design/Specific/combat-system/combat-system.md`。

如没有对应模块，则对应章节省略。

## 章节格式

1. 战斗模式：游戏战斗采用回合制、动作、自动战斗或者其他类型。
2. 单场战斗流程：如何算作单场或单局战斗开始，如何算作结束，胜负条件是什么。
3. 回合结算流程：如果这是回合制或半回合制游戏，描述游戏每个回合从开始到结束的各个阶段结算流程。
4. 伤害结算流程：游戏的伤害结算需要考虑哪些因素，整体结算完整流程是怎样的。
5. Buff 系统：游戏是否有 buff 或 debuff 系统，如何结算。
6. 单位系统：战斗中的单位分为几类，例如英雄、小兵、召唤物等；它们的创建和死亡或销毁结算是怎样的，是否有特殊之处。
7. 单位属性：单位属性如何影响战斗计算、有哪些主要属性、是否有主属性与派生属性之分。
8. 主要的本地配置：CSV 表、ScriptableObject、json 等配置项。
9. 其他
10. 参考图（可选）：放在所有适用章节之后；前面章节省略时按正文现有章节连续编号，按 `design-doc-format` 的参考图规则记录当前战斗截图。
