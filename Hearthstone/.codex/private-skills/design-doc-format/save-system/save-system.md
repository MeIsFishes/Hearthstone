# 存档系统设计文档格式

如果游戏有存档系统，则应当写一篇存档系统文档。

只在当前任务上下文涉及存档系统时检查或编写。

文档 `.md` 文件名和文件夹路径必须使用英文。

路径限定：存档系统设计文档是特殊设计文档，统一放在 `AutoDoc/Design/Specific/save-system/save-system.md`。

如没有对应模块，则对应章节省略。

## 章节格式

1. 存档方式：何时可以存档，例如随时、检查点、仅限战斗外等；档位数量是否有限制。
2. 自动存档：是否有自动存档功能、何时触发。
3. 存档内容：主要保存哪些内容、是否有明确不进行保存的状态。
4. 其他
5. 参考图（可选）：放在所有适用章节之后；前面章节省略时按正文现有章节连续编号，按 `design-doc-format` 的参考图规则记录当前存档界面或反馈截图。
