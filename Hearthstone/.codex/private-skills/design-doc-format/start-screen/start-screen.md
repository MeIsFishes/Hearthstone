# 开始界面设计文档格式

项目应当有一篇开始界面文档，但只在当前任务上下文涉及开始界面时检查或编写。

文档 `.md` 文件名和文件夹路径必须使用英文。

路径限定：开始界面设计文档是特殊设计文档，统一放在 `AutoDoc/Design/Specific/start-screen/start-screen.md`。

如没有对应模块，则对应章节省略。

## 章节格式

1. 开始游戏的过程：何时 loading、是否有开场动画等。
2. 主界面按钮：有哪些按钮、分别打开哪些窗口。
3. 如何开始游戏：点击开始游戏后是否需要玩家做出一些选择。
4. 参考图（可选）：放在最后，按 `design-doc-format` 的参考图规则记录当前开始界面截图。
