# 剧情系统设计文档格式

如果游戏有剧情系统，则应当写一篇剧情系统文档。

只在当前任务上下文涉及剧情系统时检查或编写。

文档 `.md` 文件名和文件夹路径必须使用英文。

路径限定：剧情系统设计文档是特殊设计文档，统一放在 `AutoDoc/Design/Specific/story-system/story-system.md`。

如没有对应模块，则对应章节省略。

## 章节格式

1. 剧情梗概
2. 剧情触发方式
2.1 触发节点：游戏会在哪些检查点触发剧情。
2.2 剧情依赖项：剧情触发是否有前置条件、如何配置关联前置条件。
3. 主要的本地配置：CSV 表、ScriptableObject、json 等配置项。
4. 剧情详细文档：在 `AutoDoc/` 下建立一个专门的目录，存放更详细的剧情文档。
5. 其他
6. 参考图（可选）：放在所有适用章节之后；前面章节省略时按正文现有章节连续编号，按 `design-doc-format` 的参考图规则记录当前剧情呈现截图。
