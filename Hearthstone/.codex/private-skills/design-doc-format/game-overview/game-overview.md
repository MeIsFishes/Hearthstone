# 游戏总览设计文档格式

项目应当有一篇游戏总览文档，但只在当前任务上下文涉及游戏整体定义时检查或编写。

文档 `.md` 文件名和文件夹路径必须使用英文。

路径限定：游戏总览设计文档是特殊设计文档，统一放在 `AutoDoc/Design/Specific/game-overview/game-overview.md`。

文档必须描述：

1. 当前游戏是一个什么类型的游戏。
2. 当前游戏是单机游戏还是网游。
3. 当前游戏主要有哪些系统。
4. 如何定义单局游戏的开始和结束。
5. 目前已有的特殊文档目录。

## 章节格式

1. 游戏类型
2. 游戏联网类型
3. 主要系统
4. 单局游戏开始与结束
5. 目前已有的特殊文档目录
6. 参考图（可选）：放在最后，按 `design-doc-format` 的参考图规则记录当前游戏整体体验截图。
