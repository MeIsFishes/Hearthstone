# 局外养成系统设计文档格式

如果游戏有局外养成系统，则应当写一篇局外养成系统文档。

只在当前任务上下文涉及局外养成系统时检查或编写。

文档 `.md` 文件名和文件夹路径必须使用英文。

路径限定：局外养成系统设计文档是特殊设计文档，统一放在 `AutoDoc/Design/Specific/meta-progression/meta-progression.md`。

如没有对应模块，则对应章节省略。

## 章节格式

1. 局外养成货币或积分：局外养成有哪几种货币或积分、如何获取局外养成货币或积分、是否有上限。
2. 局外养成方式
2.1 局外提升：局外可以得到哪些直接提升、是否需要消耗货币或积分。
2.2 局外解锁：是否有系统或内容需要满足一定条件来解锁。
2.3 主要界面：跟局外养成最相关的几个页面是什么。
3. 特殊养成：不在上述框架内的项目特色养成方式。
4. 主要的本地配置：CSV 表、ScriptableObject、json 等配置项。
5. 其他
6. 参考图（可选）：放在所有适用章节之后；前面章节省略时按正文现有章节连续编号，按 `design-doc-format` 的参考图规则记录当前局外养成截图。
