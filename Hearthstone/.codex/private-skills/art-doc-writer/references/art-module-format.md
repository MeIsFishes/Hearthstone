# 模块美术文档格式

模块美术文档固定保存为 `AutoDoc/Art/Modules/<module-name>/<module-name>.md`。

## 固定结构

严格按下列章节名称和顺序编写：

```markdown
# <模块名>美术模块文档

## 1. 模块范围

## 2. 模块风格

## 3. UI 资产风格

## 4. 图标规格

## 5. 人物规格

## 6. 场景规格

## 7. 物件规格

## 8. 参考图片

## 9. 目前已有资产列表
```

## 章节内容

### 1. 模块范围

说明模块覆盖的美术主题、图片用途和资源范围。

### 2. 模块风格

说明本模块相对美术风格总文档的风格偏向，包括形状、线条、色彩、构图或细节特征。

如果本模块与主风格一致且没有特别偏向，直接写：

> 本模块沿用美术风格总文档，无额外风格偏向。

### 3. UI 资产风格

模块包含 UI 资产时，必须引用 `AutoDoc/Art/UI/ui-art-overview.md` 中已定义的 UI 通用资产风格分组，不在模块文档中重复描述同一套 UI 风格。模块不包含 UI 资产时，本章节标题下留空。

| UI 资产或资产组 | UI 风格分组 ID | 分组名称 | 适用界面或区域 |
| --- | --- | --- | --- |
| <名称> | <UI-STYLE-001> | <UI 美术文档中的分组名称> | <本模块内使用位置> |

引用前核对分组 ID 与分组名称一致。若模块的 UI 资产不符合任何已有分组，应先在 UI 美术文档中新增风格分组，再在此处引用；不得只在模块文档中建立未被 UI 美术文档收录的 UI 风格。

### 4. 图标规格

记录模块内图标的 2D 图片生成规格。

| 图标或图标组 | 画布尺寸 | 主体占比与安全区 | 形状与线条 | 配色 | 背景 / Alpha | 视觉变体 |
| --- | ---: | --- | --- | --- | --- | --- |
| <名称> | <宽 × 高 px> | <比例或边距> | <轮廓、描边、细节> | <色板或色值> | <透明或指定背景> | <配色、等级、主题等> |

### 5. 人物规格

引用 `AutoDoc/Art/Specifications/character-specifications.md` 中采用的规格。模块不需要人物规格时，本章节标题下留空。

| 使用对象 | 采用的规格 ID | 规格分类 |
| --- | --- | --- |
| <角色、战机、坦克、机器人等> | <CHAR-001> | <分类名称> |

### 6. 场景规格

引用 `AutoDoc/Art/Specifications/scene-specifications.md` 中采用的规格。模块不需要场景规格时，本章节标题下留空。

| 使用场景 | 采用的规格 ID | 规格分类 |
| --- | --- | --- |
| <背景或场景范围> | <SCENE-001> | <分类名称> |

### 7. 物件规格

引用 `AutoDoc/Art/Specifications/object-specifications.md` 中采用的规格。模块不需要物件规格时，本章节标题下留空。

| 使用物件 | 采用的规格 ID | 规格分类 |
| --- | --- | --- |
| <道具、武器、装置等> | <OBJECT-001> | <分类名称> |

### 8. 参考图片

插入与模块风格或各类规格相关的参考图片，并说明借鉴特征。

| 参考图片 | 来源或项目内路径 | 参考特征 | 适用范围 |
| --- | --- | --- | --- |
| <图片或链接> | <来源或路径> | <形状、色彩、线条、构图等> | <模块或图标组> |

### 9. 目前已有资产列表

列出当前已存在的 2D 图片文件。

| 资产名称 | 项目内路径 | 图片内容与用途 | 尺寸 / 比例 | 文件格式 |
| --- | --- | --- | --- | --- |
| <文件名> | <相对路径> | <内容与用途> | <宽 × 高 px / 比例> | <PNG 等> |
