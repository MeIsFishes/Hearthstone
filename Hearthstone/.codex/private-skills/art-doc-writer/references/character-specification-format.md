# 人物规格文档格式

人物规格文档固定保存为 `AutoDoc/Art/Specifications/character-specifications.md`。这里的“人物”指承担角色表现的主要主体，可包括角色、战机、坦克、机器人等。

## 固定结构

```markdown
# 人物规格文档

## 1. 规格索引

## 2. 分类规格

### <规格ID> <分类名称>
```

## 1. 规格索引

同一文档可包含大角色、NPC、小角色、战机或其他分类。

| 规格 ID | 分类名称 | 适用主体 | 一句话说明 |
| --- | --- | --- | --- |
| CHAR-001 | <分类名称> | <角色、战机、坦克、机器人等> | <主要画面特征> |

## 2. 分类规格

每个分类使用一个三级标题，并填写下表：

| 项目 | 规格 |
| --- | --- |
| 规格 ID | <CHAR-001> |
| 适用主体 | <具体对象范围> |
| 图片用途 | <立绘、头像、战斗主体等> |
| 画布尺寸与比例 | <宽 × 高 px / 宽高比> |
| 主体占比与安全区 | <比例或边距> |
| 比例与轮廓 | <头身比、机体比例、主要识别点等> |
| 形状与线条 | <轮廓、描边、细节密度> |
| 配色、材质与光照 | <色板、表面表现、光源> |
| 视觉变体 | <表情、服装、型号、配色等> |
