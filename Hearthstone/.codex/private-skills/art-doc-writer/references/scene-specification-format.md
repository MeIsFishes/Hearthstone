# 场景规格文档格式

场景规格文档固定保存为 `AutoDoc/Art/Specifications/scene-specifications.md`，可包含全屏背景、战斗场景、室内场景、地图背景等多种分类。

## 固定结构

```markdown
# 场景规格文档

## 1. 规格索引

## 2. 分类规格

### <规格ID> <分类名称>
```

## 1. 规格索引

| 规格 ID | 分类名称 | 适用场景 | 一句话说明 |
| --- | --- | --- | --- |
| SCENE-001 | <分类名称> | <使用范围> | <主要画面特征> |

## 2. 分类规格

每个分类使用一个三级标题，并填写下表：

| 项目 | 规格 |
| --- | --- |
| 规格 ID | <SCENE-001> |
| 适用场景 | <具体范围> |
| 图片用途 | <全屏背景、局部背景等> |
| 画布尺寸与比例 | <宽 × 高 px / 宽高比> |
| 视角与透视 | <正视、俯视、等距、一点透视等> |
| 色彩、光照与氛围 | <色板、时段、天气、光源> |
| 视觉变体 | <时段、天气、主题等> |
