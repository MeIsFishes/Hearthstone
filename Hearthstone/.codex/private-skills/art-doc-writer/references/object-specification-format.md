# 物件规格文档格式

物件规格文档固定保存为 `AutoDoc/Art/Specifications/object-specifications.md`，可包含道具、武器、装置、建筑部件、家具和装饰物等多种分类。

## 固定结构

```markdown
# 物件规格文档

## 1. 规格索引

## 2. 分类规格

### <规格ID> <分类名称>
```

## 1. 规格索引

| 规格 ID | 分类名称 | 适用物件 | 一句话说明 |
| --- | --- | --- | --- |
| OBJECT-001 | <分类名称> | <使用范围> | <主要画面特征> |

## 2. 分类规格

每个分类使用一个三级标题，并填写下表：

| 项目 | 规格 |
| --- | --- |
| 规格 ID | <OBJECT-001> |
| 适用物件 | <具体对象范围> |
| 图片用途 | <道具图、场景物件、展示图等> |
| 画布尺寸与比例 | <宽 × 高 px / 宽高比> |
| 主体占比与安全区 | <比例或边距> |
| 视角与朝向 | <正视、侧视、俯视、等距等> |
| 比例与轮廓 | <整体比例和主要识别点> |
| 形状与线条 | <轮廓、描边、细节密度> |
