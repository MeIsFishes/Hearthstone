# 剧情系统程序文档格式

剧情系统程序文档属于特殊玩法模块文档，用于记录剧情触发、条件依赖、播放流程和剧情数据配置。

只在当前任务上下文涉及剧情系统时检查或编写。

文档 `.md` 文件名和文件夹路径必须使用英文。

路径限定：剧情系统程序文档是特殊程序文档，统一放在 `AutoDoc/Program/Specific/story-system/story-system.md`。

文档必须包含且仅包含以下章节；如果某一节当前没有内容，也保留章节标题，并写“当前未发现”或“当前无”。

## 1. 核心数据来源

### 1.1 Component

列出剧情系统直接读取、写入或依赖的 Component。

### 1.2 Csv和ScriptableObject配置项

列出剧情系统读取或依赖的 Csv 配置和 ScriptableObject 配置项。

### 1.3 剧情资源与外部文本

列出剧情脚本、文本、对话、演出资源或本地化资源的来源。

## 2. 逻辑驱动

### 2.1 System

列出驱动剧情系统主要逻辑的 System。

#### 2.1.1 重要的System顺序依赖

说明剧情系统中重要 System 之间的执行顺序依赖。

### 2.2 StageListener

列出剧情系统关联的 StageListener。

### 2.3 关联Task启动入口

说明该模块关联到哪些task启动入口，随后逐一说明每个task入口从哪张表或配置读取 task key，以及关联到哪个 TaskContext。

### 2.4 调用链路梳理

梳理剧情从触发检查、加载、播放到结束回调的主要调用链路。

## 3. 剧情触发与播放链路

### 3.1 触发节点

说明剧情会在哪些系统、阶段、检查点或玩家操作后触发。

### 3.2 前置条件与依赖

说明剧情触发依赖哪些状态、配置、存档标记或任务条件。

### 3.3 播放与跳过流程

说明剧情播放、暂停、跳过、结束和恢复游戏流程的链路。

### 3.4 剧情状态记录

说明已播放、已解锁、已跳过等剧情状态如何记录和读取。

## 4. 所属GameStage

列出剧情系统所属或依赖的 GameStage。
