# 局外养成系统程序文档格式

局外养成系统程序文档属于特殊玩法模块文档，用于记录局外货币、解锁、提升、养成界面背后的数据与逻辑。

只在当前任务上下文涉及局外养成系统时检查或编写。

文档 `.md` 文件名和文件夹路径必须使用英文。

路径限定：局外养成系统程序文档是特殊程序文档，统一放在 `AutoDoc/Program/Specific/meta-progression/meta-progression.md`。

文档必须包含且仅包含以下章节；如果某一节当前没有内容，也保留章节标题，并写“当前未发现”或“当前无”。

## 1. 核心数据来源

### 1.1 Component

### 1.2 Csv和ScriptableObject配置项

### 1.3 持久化数据

列出局外货币、解锁状态、升级状态、奖励领取状态等持久化数据的来源和保存位置。

## 2. 逻辑驱动
